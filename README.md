# Монстрик на горке

Автор игры: **Артем Смирнов, 7 лет**.

Монстрик катится вниз по снежной горке. По краям горки торчат шипы, а навстречу
едут колючие брёвна и шипастые шары, которые ездят слева направо и обратно.
Нужно объезжать их. Если монстрик врежется в шипы, появится надпись «ПРОИГРЫШ!»,
и через 3 секунды игра начнётся заново, но уже с другим монстриком: голубым
с зелёными глазками, зелёным, синим, розовым, фиолетовым или оранжевым.

## Как играть

Откройте `index.html` в любом браузере.

- Компьютер: стрелки ← → (или A / D), пробел — начать.
- Телефон или планшет: держите палец на левой или правой половине экрана.
